# Historial de prompts

- `v0_cowork_original_anonimizado.md`: la instrucción larga original (Cowork), anonimizada.
- `v1/` a `v7/`: los contratos de cada iteración (ver `DECISIONES.md`); `v5/` es el primero con ejemplos sin datos reales. El vigente (contrato v8, usado por el código v9) está en `prompts/`.

**Nota sobre v1, v2, v3 y v4:** sus ejemplos usaban (v1: dos de los valores; v2 a v4: todos) importes y números de comprobante reales de agosto (con nombres inventados). Se descubrió antes de entregar (`DECISIONES.md`, D16). En estos archivos los valores reales fueron reemplazados por marcadores del tipo `<importe-real-1>` o `<n-real-1>`: lo que se ve es la estructura y el texto exactos que se usaron, sin los números. Los prompts vigentes (v5) usan valores inventados.
